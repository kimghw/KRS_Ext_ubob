# 유밥 자동 학습 도우미 (Chrome 확장)

팝업에서 **시작**을 누르면 끝까지 자동으로 진행합니다.

1. 저장해 둔 계정으로 **자동 로그인**
2. 내 강의실의 **학습중인 과정** 목록을 가져옴 (전체 신청 과정·수료 과정은 제외)
3. 과정마다 **아직 다 듣지 않은 강의만** 골라 배속(기본 2배속)으로 재생 (중간까지 본 강의는 안 본 구간부터)
4. 강의가 끝나면 다음 미완료 강의, 과정이 끝나면 **다음 과정**으로 이동
5. 모든 과정을 마치면 알림

재생은 화면에 보이지 않는 **백그라운드 플레이어**에서 진행됩니다. 강의 페이지를 열어 둘 필요가 없고, 다른 작업을 해도 됩니다.

## 설치

1. Chrome 주소창에 `chrome://extensions` 입력
2. 오른쪽 위 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** → 이 폴더(`E:\dev\ubob`) 선택

> Chrome 116 이상이 필요합니다. 이전 버전(1.x)을 설치했었다면 확장 카드의 새로고침 버튼을 눌러 주세요.

## 사용법

1. 툴바의 확장 아이콘을 눌러 팝업을 엽니다.
2. **계정** 칸에 사이트 주소(기본 `https://krs.ubob.com`), 아이디, 비밀번호를 넣고 **저장**합니다. 저장하면 바로 로그인을 시도하고 결과를 보여줍니다 (`로그인됨 · 이름` 또는 사이트의 오류 문구). 언제든 **로그인 확인**으로 다시 확인할 수 있습니다.
3. **목록 새로고침**으로 수강 과정 목록이 제대로 오는지 확인합니다 (재생 없이 목록만 가져옴).
4. **백그라운드 자동 학습 시작**을 누릅니다. 이후는 모두 자동입니다.
5. 진행 중에는 **플레이어 화면 보기**로 자동 학습이 보고 있는 화면을 창으로 볼 수 있습니다. 창 위쪽 상태줄에 지금 열고 있는 주소, 페이지 응답 여부, 재생 위치, 진도 저장 횟수가 나옵니다. 그 창을 닫으면 다시 보이지 않는 곳에서 이어서 재생합니다.
6. 무언가 이상하면 **진단**을 누르세요. 로그인 세션, 강의 페이지 응답(HTTP 상태·헤더·플레이어 유무·프레임 감지 코드), 플레이어 상태, 진도 저장 기록을 한 번에 모아 보여주고, **진단 결과 복사**로 복사할 수 있습니다.

팝업에서 볼 수 있는 것:

- 지금 재생 중인 과정·강의, 진행 시간, 과정 진도율, **진도 저장 횟수와 마지막 저장 시각**, 이 강의의 진도율. 사이트가 진도를 저장할 때마다 갱신되므로, 이 숫자가 움직이면 실제로 학습이 기록되고 있는 것입니다. 목록의 과정 진도율도 함께 갱신됩니다.
- **학습중인 과정** 목록: 내 강의실의 "학습중인 과정" 분류만 보여줍니다. 과정별 진도와 상태(대기 / 학습 중 / 완료). 체크를 풀면 그 과정은 건너뜁니다. **목록 새로고침**은 재생 없이 목록만 가져오며, 자동 학습 중에도 누를 수 있습니다.
- **내 강의실 열기**: 사이트의 나의 강의실(`/MyPage/MyRoom`)을 탭으로 엽니다. 저장된 계정으로 먼저 로그인해 두므로 로그인 화면 없이 바로 열리고, 이미 열려 있으면 그 탭으로 이동합니다. 목록의 **과정 이름**을 누르면 그 과정 페이지가 열립니다.
- **기록**: 로그인, 과정 시작, 강의 종료, 과정 완료 등

설정:

| 설정 | 기본값 | 설명 |
|---|---|---|
| 재생 배속 | 2.0x | 과정마다 사이트가 허용하는 최대 배속을 넘지 않음 |
| 백그라운드 재생 중 소리 끄기 | 켬 | 끄면 강의 소리가 스피커로 나옴 |
| 데스크톱 알림 | 켬 | 과정 완료, 전체 완료, 확인 필요, 로그인 실패 |
| 탭에서 직접 볼 때도 자동 진행 | 켬 | 강의 페이지를 직접 열었을 때 배속·다음 강의 자동 진행 (백그라운드 학습 중에는 중복 재생을 막기 위해 쉼) |

툴바 배지: `2x` 재생 중 · `...` 준비 중 · `!` 확인 필요

## 자동으로 처리하는 것 / 사람에게 넘기는 것

자동으로 처리:

- 로그인: 브라우저에 이미 로그인돼 있으면 그 세션을 그대로 쓰고, 세션이 없거나 만료됐을 때만 저장된 계정으로 로그인합니다. 강제로 로그인하는 것은 **로그인 확인** 버튼과 계정 저장 직후만입니다.
- "학습중인 과정입니다", "다음 콘텐츠 학습을 진행하시겠습니까?", "강의 끝났습니다" 같은 진행 확인창
- 이미 완료한 강의 건너뛰기, 중간까지 본 강의는 안 본 구간부터 재생
- 같은 강의를 3번 재생해도 진도가 안 차면 그 강의는 건너뛰고 계속
- 학습이 실제로 되고 있지 않으면 강의 페이지를 자동으로 다시 불러오기: 재생 중인데 영상 시간이 30초 동안 멈춤, 90초 동안 재생이 시작되지 않음, 재생 중인데 2분 30초 동안 진도 저장이 없음, 플레이어가 3분 넘게 응답 없음. 같은 과정에서 3번 넘게 다시 불러와도 안 되면 멈추고 이유를 알려줍니다.

멈추고 알림을 보내는 것 (사람이 판단해야 하는 것):

- 서약 동의, 퀴즈·시험·설문, 학습 신청이 필요한 과정, 로그인 실패, 그 밖의 사이트 경고

이때 팝업에 **탭에서 열기**, **다시 시도**, **이 과정 건너뛰기** 버튼이 나타납니다. **플레이어 화면 보기**나 탭에서 직접 처리한 뒤 **다시 시도**를 누르면 이어서 진행합니다. 플레이어가 30초 안에 페이지를 못 열면 한 번 다시 시도하고, 그래도 안 되면 멈추고 알려줍니다.

그 밖에:

- 사이트가 정한 최대 배속(`maxSpeed`)을 넘지 않고, 배속이 막힌 과정(`noSpeed`)은 1.0배속으로 재생합니다.
- 진도 기록 API를 직접 호출하지 않습니다. 강의는 실제로 끝까지 재생되고, 진도는 사이트가 평소처럼 기록합니다.

## 동작 방식

로그인과 과정 목록은 확장 백그라운드에서 사이트 API를 직접 호출합니다 (Chrome 쿠키를 그대로 공유하므로 여기서 로그인하면 브라우저의 유밥 탭도 로그인 상태가 됩니다). 강의 재생만 플레이어에서 합니다.

일반 탭은 Chrome이 백그라운드에서 제약을 겁니다. 한 번도 화면에 보인 적 없는 탭에서는 영상 로딩을 미루고, 사용자 조작 없는 소리 재생도 막습니다. 그래서 탭 대신 확장 전용 **offscreen 문서** 안의 iframe에서 사이트를 그대로 실행합니다. 확장 페이지 안에서는 이 제약이 없습니다.

- 사이트가 `X-Frame-Options: DENY`를 보내므로, 확장 자신의 플레이어 요청(탭이 아닌 요청)에 한해서만 이 헤더를 제거합니다. 일반 탭에는 영향이 없습니다.
- 로그인 쿠키는 Chrome 쿠키 저장소를 공유합니다. 이미 Chrome에서 로그인되어 있으면 그 세션을 그대로 씁니다.
- 재생 중 로그인이 풀려 플레이어가 로그인 페이지로 가면, 백그라운드가 다시 로그인하고 과정 페이지로 돌려보냅니다.

| 파일 | 역할 |
|---|---|
| `src/background.js` | 로그인·과정 목록 API 호출, 진행 제어(과정 순서 → 완료), 감시, 알림, 배지 |
| `src/runner.html/js` | 플레이어 (사이트를 담는 iframe). 보이지 않는 offscreen 문서와 "플레이어 화면 보기" 창이 같이 씀 |
| `src/content.js` | 페이지와 확장 사이 중계 |
| `src/page.js` | 강의 페이지 안에서 동작: 배속, 미완료 강의 선택, 확인창 처리, 종료 인지 |
| `popup/` | 팝업 화면 |

사이트에서 쓰는 것:

- 로그인: 로그인 페이지와 같은 요청 `POST /api/auth/login` (userName, password)
- 과정 목록: `/api/myroom`(분류 목록) → 이름에 "학습중"이 든 분류만 `/api/myroom/$itemlist` (내 강의실과 같은 API)
- 강의별 진도: 강의 페이지의 `orderContents`의 `studyProgress`, `studyTime`, `studyTimeList`
- 재생 위치 지정: 사이트의 `fnGoPosition` (미학습 구간 이동과 같은 기능)

## 보안

- 비밀번호는 이 PC의 Chrome 프로필 안(`chrome.storage.local`)에 저장되며 동기화되지 않습니다. 암호화되지는 않으므로 공용 PC에서는 쓰지 마세요.
- 비밀번호는 설정한 `https://○○○.ubob.com` 사이트의 로그인 요청(`/api/auth/login`)에만 보냅니다.

## 문제 해결

- **로그인 실패**: 계정 칸에 사이트가 보낸 오류 문구가 그대로 나옵니다. **변경**에서 아이디·비밀번호·사이트 주소를 확인하세요. 비밀번호 변경 안내 등이 뜨는 계정이면 먼저 브라우저에서 직접 로그인해 처리해 주세요.
- **"로그인 응답은 성공했지만 로그인 상태가 유지되지 않습니다"**: Chrome 설정 → 개인정보 보호 및 보안 → 서드 파티 쿠키에서 `ubob.com`을 허용해 보세요.
- **"로그인이 짧은 시간에 반복해서 풀립니다"**: 이 사이트는 같은 계정으로 다른 곳(다른 PC·브라우저·모바일 앱)에서 로그인하면 기존 로그인이 풀립니다. 두 곳이 동시에 자동 학습을 돌리면 서로 상대의 로그인을 끊어 진도 저장이 실패하고 같은 구간을 반복합니다. 한 곳에서만 사용하세요.
- **어디서 멈췄는지 모를 때**: **진단**을 누르고 결과를 확인하세요. 팝업 맨 아래 **기록**에도 단계별로 남습니다. 진행 중이면 **플레이어 화면 보기**로 실제 화면과 상태줄을 확인하세요.
- **플레이어 화면이 하얗게 비어 있음**: 상태줄이 "페이지가 열렸지만 아직 응답이 없습니다"이면 사이트가 프레임 안에서 내용을 숨기는 경우일 수 있습니다. 진단의 "프레임 감지 의심 코드" 줄을 확인하세요. "열어야 할 주소를 기다리는 중"이면 자동 학습이 과정 단계까지 가지 않은 것입니다.
- **"확인이 필요합니다"에서 멈춤**: **탭에서 열기**로 해당 과정을 열어 서약·설문 등을 처리한 뒤 **다시 시도**.
- **확장을 새로고침(업데이트)했을 때**: 자동 학습이 실행 중이었다면 진행 중이던 과정부터 자동으로 이어서 진행합니다. 브라우저를 완전히 종료했다가 다시 켠 경우에는 멈추므로 팝업에서 다시 시작하세요.
- **기록에 "플레이어가 다른 페이지(…)로 이동해 과정 페이지로 돌아갑니다"가 반복됨**: 2.0.0 초기 버전의 버그였습니다. 강의 페이지 안에 든 개인정보처리방침 iframe을 플레이어 본체로 잘못 인식한 것으로, 확장을 새로고침하면 해결됩니다.
- **사이트가 바뀌어 동작하지 않음**: 확인창 문구는 `src/page.js`의 `RULES`, 로그인과 과정 목록 API는 `src/background.js`의 `login()`, `fetchCourses()`에 있습니다.
